[ 포트폴리오 웹사이트 프로젝트 업로드 가이드 ]

이 웹사이트는 코드 수정 없이, 폴더와 이미지 파일만 규칙에 맞게 넣으면 
자동으로 홈페이지 목록과 상세페이지가 생성되도록 설계되어 있습니다.

-----------------------------------------------------------
1. 폴더 구조 규칙 (연도별 분류)
-----------------------------------------------------------
이 문서를 보고 계신 폴더(index.html과 같은 위치) 안에 
반드시 [ projects ] 라는 이름의 폴더가 있어야 합니다.

새로운 작품을 추가할 때는 그 projects 폴더 안에
먼저 [ 연도별 폴더 ] (예: 2026, 2025...)를 만들고, 
그 안에 [ 번호 폴더 ] (예: 1, 2, 3...)를 만듭니다.

📁 Portfolio Web/
 ┣ 📄 index.html.html
 ┣ 📁 about/
 ┃ ┗ 📄 about.txt          (About 페이지 정보 수정용)
 ┣ 📄 프로젝트_업로드_가이드.txt
 ┗ 📁 projects/
    ┣ 📁 2026/
    ┃ ┣ 📁 1/
    ┃ ┃ ┣ 📄 info.txt       (상세 설명, 제목, 카테고리 등 작성)
    ┃ ┃ ┣ 🖼️ thumbnail.jpg  (홈 화면에 보일 썸네일 이미지)
    ┃ ┃ ┣ 🖼️ 1.jpg          (상세 페이지 스크롤 이미지 1)
    ┃ ┃ ┣ 🖼️ 2.png          (.png 파일도 사용 가능!)
    ┃ ┃ ┗ 🖼️ 3.gif          (.gif 움짤도 가능!)
    ┃ ┣ 📁 2/
    ┃ ┃ ┣ 📄 info.txt
    ┃ ┃ ...
    ┣ 📁 2025/
    ┃ ┣ 📁 1/
    ┃ ...


-----------------------------------------------------------
2. 정렬 순서 및 우선순위
-----------------------------------------------------------
- 홈 화면에 보여지는 순서는 [ 연도가 높은(최신) 폴더 ]가 최우선입니다. (예: 2026이 2025보다 먼저 나옴)
- 같은 연도 안에서는 [ 번호가 높은 폴더 ]가 위에 올라갑니다. (가장 나중에 만든 높은 숫자가 제일 먼저 보여집니다.)


-----------------------------------------------------------
3. info.txt 작성 방법
-----------------------------------------------------------
각 프로젝트 번호 폴더 안(예: 2026/1/)에 메모장을 열어 [ info.txt ]를 만들고 
다음과 같은 형식으로 작성해주세요. (Year 필드는 더 이상 필수값이 아닙니다!)

Title: Project Title 01
Category: Branding
Contribution: Brand Design, Art Direction
Client: Gallery Lull
Color: #161616
===
(여기에 상세 설명을 적습니다. === 아래 부분은 모두 설명 문구로 처리됩니다)
엔터를 쳐서 여러 줄을 작성하면, 자동으로 문단이 띄어쓰기 되어 반영됩니다.
작업 배경, 기획 의도 등 편하게 줄글로 적어주시면 됩니다.

* 주의: 
- 영어 철자와 콜론(:) 형식을 꼭 지켜주세요!
- Color는 썸네일 커버 색상입니다.
- 카테고리 (Branding, UI/UX, Marketing, Editorial, Web Design 등)는 홈페이지 필터와 연동됩니다!
- info.txt에 Year: 2024 라고 억지로 적어넣으면, 폴더 연도 구조보다 그것을 우선 적용하게 됩니다.


-----------------------------------------------------------
4. 작동 원리와 테스트 환경 (매우 중요)
-----------------------------------------------------------
[ 이미지 연쇄 로딩 ]
- 상세 페이지로 들어가면 그 폴더 안에 있는 1.jpg 부터 번호순으로 끝없이 찾아서 보여줍니다. 빈 번호가 있거나 포맷이(jpg, png, gif) 섞여있어도 막힘없이 다 찾아옵니다!

[ ⚠️ 테스트 시 주의사항 ]
- 이 방식은 내 컴퓨터의 파일을 동적으로 읽어옵니다. 보안 정책 때문에 단순히 index.html 파일을 바탕화면에서 더블클릭해서 열면 화면이 나오지 않고 오류 메시지가 뜹니다.
- 확인하실 때는 반드시 VS Code에서 "Open with Live Server" 기능으로 열어서 보셔야 합니다!
- 나중에 GitHub에 업로드해서 호스팅(Cloudflare 연동 등)이 완료된 상태에서는 인터넷이 연결된 환경이므로 완전 정상 작동합니다.
